# Quick start — NULL//ENTITY

- Open `res://scenes/null_entity_lab.tscn` in Godot 4.7.x.
- Press **F6** to run the scene without changing the project's default startup scene.
- Move with **WASD** or arrow keys.
- Attacks target the nearest enemy automatically.
- Press **R** after defeat to restart.

See [NULL_ENTITY_PROTOTYPE.md](NULL_ENTITY_PROTOTYPE.md) for scope and limitations.
