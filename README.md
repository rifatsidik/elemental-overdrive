# ELEMENTAL OVERDRIVE

A landscape Android survivor-action game built with Godot 4.7.

## Vision

A high-intensity survivor game built around gesture-driven lightning executions, escalating kill chains, and extravagant neon energy effects. The goal is a maintainable game foundation—not a throwaway prototype.

## Development principles

- Modular gameplay systems: player, enemies, combat, gesture execution, progression, and visual effects.
- Android landscape first, with desktop controls for rapid iteration.
- Readable combat feedback despite intense bloom, particles, screen shake, and lightning.
- Performance budgets from the beginning: pooled effects, bounded particles, and scalable visual quality.
- Small commits that can be tested locally in Godot.

## Current milestone

**Milestone 0 — Project foundation.** Establish the Godot project and a minimal playable arena foundation before adding the full gesture-combo and VFX systems.

## Requirements

- Godot Engine 4.7.x
- Git

## Run locally

Open this folder in Godot and press **F6** to run the current scene, or **F5** to run the project.

## Controls

The initial foundation uses keyboard movement. Gesture execution and mobile touch controls will be added as a dedicated combat system in a later milestone.
